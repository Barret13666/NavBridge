# NavBridge
Небольшое Android-приложение: транслирует местоположение телефона (GPS на улице, Wi-Fi/сеть в помещении — автоматически) стандартными NMEA 0183 сообщениями по UDP. Строит маршруты для навигации на приборке полностью офлайн через отдельно установленное приложение BRouter, без своего сервера. Для самодельных GPS-навигаторов и ESP32/Arduino-проектов.
